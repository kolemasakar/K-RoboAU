# K-RoboAU

RoboAU 1 is a standalone MetaTrader 4 Expert Advisor under development for XAUUSD. It reproduces the verified Strategy A v1.0 breakout/retest/continuation research rules with a fixed 3R target. Initial release target is DEMO. LIVE permission defaults to false and requires owner action after validation.

No K_AI runtime, Bridge, Python service, SQLite or external provider is required.
